Kubernetes Security Project

DVWA Deployment on Kubernetes

A hands-on project demonstrating the deployment of Damn Vulnerable Web Application (DVWA) in a local Kubernetes environment using Minikube, Docker, and Kubernetes resources.

View Source Code

Project Overview

This project deploys a deliberately vulnerable web application alongside a MariaDB database in Kubernetes. It demonstrates application deployment, service configuration, and controlled web security testing.

Technologies Used

Kubernetes

Pods, deployments, services, and container orchestration.

Minikube

Local Kubernetes cluster for development and testing.

Docker

Container-based application deployment.

DVWA and MariaDB

Web application security testing and database services.

Security Testing Demonstrations

01. SQL Injection

Tested an SQL injection input and observed the resulting database query behavior in the controlled DVWA lab.

02. Reflected XSS

Tested a JavaScript payload to demonstrate how untrusted input can execute in a browser.

03. Command Injection

Investigated command injection in DVWA. Refer to the repository documentation for the recorded test results.

Security Notice

DVWA is intentionally vulnerable and must be used only in an isolated, authorized testing environment. This GitHub Pages website showcases the project; it does not run the DVWA application itself.
